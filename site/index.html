One CLI. 31 audit tools. Zero config.

Cogent is the unified security audit & compliance platform — a single Rust binary that replaces SonarQube, CodeQL, Snyk, and Slither. It speaks JSON, NDJSON, and SARIF natively, and is built for CI/CD gatekeeping and autonomous AI agents.

How it works

Three commands. One deterministic pipeline.

Initialize

Run cogent init to auto-detect your languages and frameworks. It writes a tuned .quality.toml with sensible thresholds.

Check

Run cogent check . to execute all 31 audit engines in parallel. Exit code 0 means the gate passed.

Report

Run cogent report . --open for an HTML breakdown, or pipe JSON/SARIF into your CI or agent.

Why Cogent

Modern security auditing is fragmented — every tool brings its own CI job, config file, and dashboard. Cogent collapses the whole stack into one deterministic gate.

Single binary

No JVM, no cloud token, no per-seat pricing. Drop one Rust binary into CI and run cogent check ..

Machine-first output

Everything a human sees, an agent or CI job can parse — JSON, NDJSON, and SARIF for the GitHub Security tab.

Deterministic gates

Same input, same exit code. 0 pass, 1 fail, 2 error — built for hard CI gatekeeping.

Zero config

cogent init auto-detects 10+ languages and writes tuned thresholds. Everything works on defaults first.

Coverage-aware

CRAP scoring and mutation testing measure real defect-detection capability, not just line counts.

AI-native

Ships with Hermes agent skills and an MCP server for Claude Desktop, Cursor, and Windsurf.

Install & run in 60 seconds

macOS (Homebrew) 

brew tap kidikaros/cogent
brew install cogent

Linux (binary) 

curl -LO https://github.com/KidIkaros/cogent/releases/latest/download/cogent-linux-x86_64.tar.gz
tar xzf cogent-linux-x86_64.tar.gz
sudo cp cogent-linux-x86_64/cogent /usr/local/bin/

From source 

git clone https://github.com/KidIkaros/cogent.git
cd cogent
cargo build --release --workspace

First run 

cogent init          # detect ecosystem
cogent check .       # run all 31 checks
cogent report . --open   # HTML report
