Why Cogent?

Modern security auditing is fragmented. Cogent collapses the whole stack into one deterministic gate.

Single binary

No JVM, no cloud token, no per-seat pricing. Drop one Rust binary into CI and run cogent check .

Machine-first output

JSON · NDJSON · SARIF for CI and agents. Everything a human sees, an agent can parse.

Deterministic gates

Same input, same exit code. 0 pass, 1 fail, 2 error — built for hard CI gatekeeping.

Zero config

cogent init auto-detects 10+ languages and writes tuned thresholds. Everything works on defaults.

Coverage-aware

CRAP scoring and mutation testing measure real defect-detection capability, not just line counts.

AI-native

Ships with Hermes agent skills and an MCP server for Claude Desktop, Cursor, and Windsurf.

Install in 60 seconds

Choose your platform and copy the commands below.

brew tap kidikaros/cogent
brew install cogent
curl -LO https://github.com/KidIkaros/cogent/releases/latest/download/cogent-linux-x86_64.tar.gz
tar xzf cogent-linux-x86_64.tar.gz
sudo cp cogent-linux-x86_64/cogent /usr/local/bin/
winget install cogent
docker pull ghcr.io/kidikaros/cogent:latest
docker run --rm -v $(pwd):/app ghcr.io/kidikaros/cogent:latest check .
cargo install --git https://github.com/KidIkaros/cogent.git
